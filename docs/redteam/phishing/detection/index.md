## Detection

Los avances en la detección de phishing han facilitado la identificación de sitios web maliciosos mediante diversos métodos de identificación que, en ocasiones, no resultan evidentes a simple vista. Además, los sitios web se analizan desde múltiples fuentes, como escáneres de internet, navegadores, proveedores de correo electrónico y otros servicios de seguridad, que emplean técnicas de detección tanto pasivas como activas para evaluar su legitimidad. 
Por consiguiente, un sitio web de phishing debe estar diseñado para resistir estos sistemas de detección si se pretende que siga operativo durante un periodo prolongado.
